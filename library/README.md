# 자료실 파일 폴더

여기에 PDF 를 올리면 사이트 자료실에 자동으로 나타납니다.

## 올리는 법

1. GitHub 에서 이 폴더를 엽니다.
2. **Add file → Upload files** 를 누릅니다.
3. 파일을 끌어다 놓고 **Commit changes** 를 누릅니다.

1~2분 뒤 사이트 자료실에 뜹니다.

## 분류하려면

이 폴더 안에 폴더를 만들면 그 이름이 분류가 됩니다.

```
library/
  교육과정/
    2022개정_국어과_교육과정.pdf
  보고서/
    북한인권백서_2026.pdf
```

폴더 없이 그냥 올린 파일은 "기타 자료" 로 묶입니다.

## 제목

파일 이름이 그대로 제목이 됩니다. 밑줄(_)은 띄어쓰기로 바뀝니다.
`2022개정_국어과_교육과정.pdf` → `2022개정 국어과 교육과정`

## 주의

저장소가 공개라 **올린 파일은 누구나 받을 수 있습니다.** 배포가 제한된
자료는 올리지 마세요. 사이트 전체 용량 상한은 1GB 입니다.
